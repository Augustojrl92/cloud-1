# Cloud-1

Estructura inicial del proyecto Cloud-1.

- `terraform/`: configuración inicial de Terraform para Google Cloud.
- `ansible/`: reservado para futura configuración de servidores.
- `docker/`: reservado para futura configuración de contenedores.

Actualmente Terraform solo declara el proveedor y las variables del proyecto;
no contiene recursos y no crea infraestructura.
